## 📌 Technical Overview
**AnimatedProgressBar** provides modular, reusable visual indicators engineered with custom SwiftUI `Shape` pathing, stroke animation trimming, and spring physics.

### 💼 Technical Highlights
- **Custom Vector Pathing**: Implements `Circle` and `Capsule` trimming with `.stroke(style: ...)` modifiers.
- **Spring Animation Transitions**: Smooth progress interpolations with spring physics and percentage labels.
- **Drop-In Component Architecture**: Highly configurable color gradients, stroke widths, and completion triggers.

## 🚀 Setup & Run
1. Clone the repository:
   ```bash
   git clone https://github.com/snaimio/AnimatedProgressBar2026.git
   cd AnimatedProgressBar2026
   open AnimatedProgressBar2026.xcodeproj
   ```
2. Build and run in Xcode (`⌘ + R`).

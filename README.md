## 📌 Technical Overview

**Animated Progress Bar** provides a modular suite of reusable progress gauges and animated loading indicators built with **SwiftUI**. Demonstrates vector shape trimming (`.trim(from:to:)`), interactive step increments, and physics-based spring animations.

---

## ✨ Key Features

- **Linear & Circular Gauges**: Reusable component views adapting dynamically to percentage inputs.
- **Physics-Based Spring Animations**: Smooth transitions on value updates with customizable damping curves.
- **Accessible Design Tokens**: Dynamic contrast support and semantic color state bindings.
